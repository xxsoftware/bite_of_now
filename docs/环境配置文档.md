# "咬一口春天" 环境配置文档

## 1. 系统要求

| 项目 | 最低版本 | 推荐版本 |
|------|----------|----------|
| Node.js | 20.x | 22.x LTS |
| pnpm | 9.x | 9.x |
| Rust | 1.77.2 | 1.85+ |
| Tauri CLI | 2.0.0 | 最新 |
| OS | Windows 10 / macOS 12 / Ubuntu 22.04 | 最新 |

---

## 2. 前置依赖安装

### 2.1 Node.js + pnpm

**Windows (使用 scoop)**:
```powershell
scoop install nodejs-lts pnpm
```

**macOS (使用 Homebrew)**:
```bash
brew install node pnpm
```

**验证安装**:
```bash
node -v   # v22.x.x
pnpm -v   # 9.x.x
```

### 2.2 Rust 工具链

**Windows**:
```powershell
# 下载并运行 rustup-init.exe
# https://rustup.rs/
```

**macOS / Linux**:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
```

**验证安装**:
```bash
rustc --version    # 1.85.0+
cargo --version    # 1.85.0+
```

### 2.3 Tauri 系统依赖

**Windows**:
需要安装 Microsoft C++ 生成工具和 WebView2：

```powershell
# 1. 安装 Visual Studio Build Tools
# 下载: https://visualstudio.microsoft.com/visual-cpp-build-tools/
# 勾选: 使用 C++ 的桌面开发

# 2. WebView2 运行时（Windows 10/11 通常已预装）
# 如需安装: https://developer.microsoft.com/microsoft-edge/webview2/
```

**macOS**:
```bash
xcode-select --install
```

**Linux (Ubuntu/Debian)**:
```bash
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

## 3. 项目初始化

### 3.1 克隆仓库

```bash
cd d:\Desktop\bite_of_now
```

### 3.2 安装依赖

```bash
# 安装前端依赖
pnpm install

# 进入 Tauri 目录安装 Rust 依赖
cd src-tauri
cargo fetch
cd ..
```

### 3.3 批准构建脚本（首次）

```bash
pnpm approve-builds
```

---

## 4. 开发模式启动

### 4.1 启动前端开发服务器

```bash
pnpm dev
```

服务将启动在 http://localhost:1420

### 4.2 启动 Tauri 开发模式（完整 App）

```bash
pnpm tauri:dev
```

这将同时启动前端 dev server 和 Tauri 桌面窗口。

### 4.3 常用脚本

| 命令 | 功能 |
|------|------|
| `pnpm dev` | 仅启动前端开发服务器 |
| `pnpm build` | 构建生产环境前端代码 |
| `pnpm tauri:dev` | 启动 Tauri 开发模式 |
| `pnpm tauri:build` | 构建 Tauri 生产包 |
| `pnpm tauri:android:dev` | 启动 Android 开发模式 |
| `pnpm tauri:ios:dev` | 启动 iOS 开发模式（仅 macOS）|

## 5. IDE 配置

### 5.1 VS Code 推荐插件

```json
{
  "recommendations": [
    "bradlc.vscode-tailwindcss",
    "rust-lang.rust-analyzer",
    "tauri-apps.tauri-vscode",
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",
    "yoavbls.pretty-ts-errors"
  ]
}
```

### 5.2 TypeScript 配置要点

`tsconfig.json`:
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "jsx": "react-jsx",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    },
    "ignoreDeprecations": "6.0"
  }
}
```

### 5.3 Vite 配置

`vite.config.ts`:
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'
import path from 'path'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: { '@': path.resolve(__dirname, './src') },
  },
  server: {
    port: 1420,
    strictPort: true,
  },
  build: {
    target: 'es2022',
    minify: 'esbuild',
  },
})
```

## 7. 常见问题排查

### 7.1 `esbuild` 找不到

```bash
pnpm approve-builds esbuild
pnpm rebuild esbuild
```

### 7.2 Tailwind CSS v4 `@theme` 报错

确保已安装 `@tailwindcss/vite` 并在 `vite.config.ts` 中引入：

```typescript
import tailwindcss from '@tailwindcss/vite'
```

### 7.3 TypeScript `baseUrl` 弃用警告

已在 `tsconfig.json` 中添加 `"ignoreDeprecations": "6.0"`。

### 7.4 Rust 编译失败

```bash
# 更新 Rust 工具链
rustup update

# 清理并重试
cargo clean
cd src-tauri && cargo build
```

### 7.5 pnpm 安装超时

```bash
# 切换国内镜像
pnpm config set registry https://registry.npmmirror.com
```
