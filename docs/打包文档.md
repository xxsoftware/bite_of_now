# "咬一口春天" 打包文档

## 1. 打包概述

本项目使用 **Tauri 2.0** 进行跨平台打包，支持以下目标平台：

| 平台 | 格式 | 说明 |
|------|------|------|
| Windows | `.msi`, `.exe` | 桌面安装包 |
| macOS | `.dmg`, `.app` | 应用包 |
| Linux | `.deb`, `.rpm`, `.AppImage` | 发行版包 |
| Android | `.apk`, `.aab` | 移动安装包 |
| iOS | `.ipa` | 移动安装包（需开发者证书）|

## 3. 各平台打包流程

### 3.1 Windows 桌面端

**前置条件**:
- Visual Studio Build Tools（含 C++ 桌面开发）
- WebView2 运行时

**打包命令**:
```bash
# 构建并打包
pnpm tauri:build

# 输出目录
# src-tauri/target/release/bundle/msi/*.msi
# src-tauri/target/release/bundle/nsis/*.exe
```

**仅构建前端**:
```bash
pnpm build
# 输出: dist/ 目录
```

---

### 3.2 macOS 桌面端

**前置条件**:
- macOS 系统
- Xcode Command Line Tools

**打包命令**:
```bash
# 构建并打包
pnpm tauri:build

# 输出目录
# src-tauri/target/release/bundle/dmg/*.dmg
# src-tauri/target/release/bundle/macos/*.app
```

**签名（可选，发布到 App Store 必需）**:
```bash
# 在 tauri.conf.json 中配置签名
"bundle": {
  "macOS": {
    "signingIdentity": "Developer ID Application: Your Name",
    "entitlements": "./Entitlements.plist"
  }
}
```

---

### 3.3 Linux 桌面端

**前置条件**:
```bash
# Ubuntu/Debian
sudo apt install libwebkit2gtk-4.1-dev build-essential
```

**打包命令**:
```bash
pnpm tauri:build

# 输出目录
# src-tauri/target/release/bundle/deb/*.deb
# src-tauri/target/release/bundle/rpm/*.rpm
# src-tauri/target/release/bundle/appimage/*.AppImage
```

---

### 3.4 Android

**前置条件**:
- Android Studio
- Android SDK (API 33+)
- NDK
- 环境变量 `ANDROID_HOME`

**配置**:
```bash
# 生成 Android 项目（首次）
pnpm tauri android init

# 启动开发模式
pnpm tauri:android:dev

# 构建 Release APK
pnpm tauri android build

# 构建 Release AAB（Google Play 上架）
pnpm tauri android build --aab
```

**输出目录**:
```
src-tauri/gen/android/app/build/outputs/apk/
src-tauri/gen/android/app/build/outputs/bundle/
```

---

### 3.5 iOS

**前置条件**:
- macOS 系统
- Xcode 15+
- Apple Developer 账号（真机调试/上架）

**配置**:
```bash
# 生成 iOS 项目（首次）
pnpm tauri ios init

# 启动开发模式
pnpm tauri:ios:dev

# 构建
pnpm tauri ios build
```

## 4. 应用图标配置

### 4.1 图标目录

图标文件存放于 `src-tauri/icons/`:

| 文件名 | 尺寸 | 用途 |
|--------|------|------|
| `32x32.png` | 32x32 | 任务栏图标 |
| `128x128.png` | 128x128 | 桌面图标 |
| `128x128@2x.png` | 256x256 | 高 DPI 桌面图标 |
| `icon.icns` | 多尺寸 | macOS 图标包 |
| `icon.ico` | 多尺寸 | Windows 图标包 |

### 4.2 生成图标

准备一张 1024x1024 的 PNG 图标，然后使用 Tauri CLI 生成：

```bash
pnpm tauri icon path/to/your/icon.png
```

这将自动生成所有平台所需尺寸的图标。

## 5. 应用签名

### 5.1 Windows 代码签名

**使用 signtool（需购买代码签名证书）**:

```powershell
signtool sign /f certificate.pfx /p password "咬一口春天_0.1.0_x64-setup.exe"
```

**或在 tauri.conf.json 中配置**:
```json
{
  "bundle": {
    "windows": {
      "certificateThumbprint": "YOUR_CERT_THUMBPRINT",
      "digestAlgorithm": "sha256"
    }
  }
}
```

### 5.2 macOS 代码签名

```bash
# 使用 codesign
codesign --deep --force --verify --verbose --sign "Developer ID Application: Your Name" "咬一口春天.app"

# 公证（Notarization）
xcrun notarytool submit "咬一口春天.dmg" --apple-id your@email.com --team-id TEAM_ID --wait
```

### 5.3 Android 签名

```bash
# 生成密钥库
keytool -genkey -v -keystore bite-of-now.keystore -alias biteofnow -keyalg RSA -keysize 2048 -validity 10000

# 配置签名（src-tauri/gen/android/app/build.gradle.kts）
signingConfigs {
    create("release") {
        storeFile = file("../../../bite-of-now.keystore")
        storePassword = System.getenv("STORE_PASSWORD")
        keyAlias = "biteofnow"
        keyPassword = System.getenv("KEY_PASSWORD")
    }
}
```

## 6. 发布流程

### 6.1 内部测试

**Windows**:
```bash
# 生成安装包后直接分发 .msi 或 .exe
```

**Android**:

### 6.2 应用商店发布

| 平台 | 商店 | 步骤 |
|------|------|------|
| Android | Google Play | 1. 注册开发者账号<br>2. 上传 AAB 包<br>3. 填写应用信息 |
| Android | 国内应用市场 | 1. 注册各平台开发者<br>2. 上传 APK<br>3. 等待审核 |
| iOS | App Store | 1. 注册 Apple Developer<br>2. 使用 Xcode Archive<br>3. 上传至 App Store Connect |
| Windows | Microsoft Store | 1. 注册合作伙伴中心<br>2. 提交 MSIX 包 |
| macOS | Mac App Store | 1. 使用 Xcode 上传<br>2. 等待审核 |

### 6.3 自动更新配置

Tauri 2.0 内置更新功能，需在 `tauri.conf.json` 中配置：

```json
{
  "plugins": {
    "updater": {
      "active": true,
      "endpoints": ["https://your-domain.com/updates.json"],
      "dialog": true,
      "pubkey": "YOUR_PUBLIC_KEY"
    }
  }
}
```

## 7. 构建优化

### 7.1 前端体积优化

当前构建输出：
```
dist/assets/index-xxx.css   54.21 kB (gzip: 8.39 kB)
dist/assets/index-xxx.js   472.56 kB (gzip: 149.70 kB)
```

**优化建议**:

1. **代码分割**（路由级别）:
```typescript
// App.tsx
const Home = lazy(() => import('./pages/Home'))
const Explore = lazy(() => import('./pages/Explore'))
```

2. **按需加载图标**:
```typescript
// 目前使用全量导入，可改为按需
import { Home } from 'lucide-react'  // 当前方式
import Home from 'lucide-react/dist/esm/icons/home'  // 优化方式
```

3. **Tree Shaking**:
确保 `package.json` 中 `"sideEffects": false`

### 7.2 Rust 构建优化

在 `src-tauri/Cargo.toml` 中添加：

```toml
[profile.release]
panic = "abort"
codegen-units = 1
lto = true
opt-level = "s"  # 优化体积（或 "3" 优化速度）
strip = true
```

## 8. CI/CD 配置

### 8.1 GitHub Actions 示例

`.github/workflows/release.yml`:

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    strategy:
      matrix:
        platform: [ubuntu-latest, windows-latest, macos-latest]
    runs-on: ${{ matrix.platform }}
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 22
      
      - name: Setup pnpm
        uses: pnpm/action-setup@v2
        with:
          version: 9
      
      - name: Setup Rust
        uses: dtolnay/rust-action@stable
      
      - name: Install dependencies
        run: pnpm install
      
      - name: Build Tauri
        uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          tagName: v__VERSION__
          releaseName: "咬一口春天 v__VERSION__"
          releaseBody: "See the assets to download this version and install."
          releaseDraft: true
          prerelease: false
```

## 9. 调试包 vs 发布包

| 类型 | 命令 | 说明 |
|------|------|------|
| 开发调试 | `pnpm tauri:dev` | 热重载、开发者工具 |
| 前端生产 | `pnpm build` | 仅构建前端到 dist/ |
| 桌面调试 | `cargo run --manifest-path src-tauri/Cargo.toml` | Rust 调试构建 |
| 桌面发布 | `pnpm tauri:build` | 优化后的生产包 |
| 移动调试 | `pnpm tauri:android:dev` / `pnpm tauri:ios:dev` | 真机/模拟器调试 |
| 移动发布 | `pnpm tauri android build` / `pnpm tauri ios build` | 签名后的发布包 |

## 10. 常见问题

### Q: 打包时提示 icon 缺失？
A: 运行 `pnpm tauri icon src-tauri/icons/source.png` 生成全套图标。

### Q: Windows 打包提示找不到 WebView2？
A: 在 `tauri.conf.json` 的 `bundle.windows` 中配置 `webviewInstallMode`。

### Q: Android 打包失败，提示 NDK 版本不匹配？
A: 在 `src-tauri/gen/android/build.gradle.kts` 中统一 NDK 版本。

### Q: 如何减小安装包体积？
A: 1) 前端启用代码分割 2) Rust 启用 LTO 优化 3) 移除不必要的依赖。
