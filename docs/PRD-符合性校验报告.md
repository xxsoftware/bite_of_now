## 关键缺失清单（按优先级排序）

### P0 - 阻塞发布
1. **本地数据库**（SQLite）- 所有数据持久化依赖此功能
2. **AI 推荐逻辑** - 组装 Prompt、调用 API、解析响应
3. **"我吃了"保存逻辑** - 将推荐菜品写入饮食记录
4. **真实数据导入/导出** - JSON 文件的读写与分享

### P1 - 核心体验
5. **食谱上传表单** - 用户自定义食谱录入页面
6. **烹饪模式** - 屏幕常亮、字体放大、语音播报
7. **视频播放** - 真实视频嵌入与倍速/打点
8. **API Key 加密存储** - Tauri 安全存储插件

### P2 - 体验优化
9. **深色模式** - Tailwind dark 变体配置
10. **过季菜品提示** - 根据当前日期计算并显示提示
11. **智能分类** - 食材名称自动归类算法
12. **性能优化** - 冷启动、大数据量检索优化
