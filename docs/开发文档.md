## 5. 页面架构

### 5.1 路由表

| 路径 | 页面 | 底部导航 |
|------|------|----------|
| `/` | 首页 (Home) | ✅ |
| `/explore` | 探索页 (Explore) | ✅ |
| `/recipe/:id` | 菜谱详情 (RecipeDetail) | ❌ |
| `/records` | 饮食记录 (DietRecords) | ✅ |
| `/shopping` | 购物清单 (ShoppingList) | ✅ |
| `/settings` | 设置页 (Settings) | ✅ |

### 5.2 页面切换动画

使用 Framer Motion `AnimatePresence` + `motion.div`：

- **Tab 页**：Y 轴滑动 + 淡入淡出（duration: 0.25s, ease: easeOut）
- **详情页**：纯淡入淡出（duration: 0.2s）

### 5.3 底部导航动画

- 活跃标签背景：`layoutId="activeTab"` 弹性滑动
- 图标粗细变化：活跃 2.5 / 非活跃 1.8

## 6. 数据模型

### 6.1 核心类型

```typescript
interface Recipe {
  id: string
  name: string
  cuisine: string           // 菜系
  flavor: string            // 味型
  difficulty: 'easy' | 'medium' | 'hard'
  time: number              // 分钟
  calories: number          // 千卡
  bestSeason: string[]      // 最佳时令，如 ["5月下旬"]
  ingredients: Ingredient[]
  steps: Step[]
  image?: string
  video?: string
  tips?: string
}

interface DietRecord {
  id: string
  date: string              // YYYY-MM-DD
  recipe: Recipe
  mealType: 'breakfast' | 'lunch' | 'dinner' | 'snack'
  fullness: 'hungry' | 'comfortable' | 'full'
  mood: string
}

interface ShoppingItem {
  id: string
  name: string
  category: string          // 蔬菜/水果/肉类/水产/蛋奶/粮油/调料
  checked: boolean
  sourceRecipe?: string
}

interface AIConfig {
  apiKey: string
  baseUrl?: string
  modelName?: string
}
```

### 6.2 当前数据来源

所有数据来自 `src/data/mock.ts`，共 6 道食谱、3 条饮食记录、5 条购物清单项。

## 8. 后续开发指南

### 8.1 接入 SQLite 数据库

建议方案：使用 Tauri 的 `tauri-plugin-sql` 或直接在 Rust 端使用 `rusqlite`。

需要创建的表：

```sql
CREATE TABLE recipes (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  cuisine TEXT,
  flavor TEXT,
  difficulty TEXT,
  time INTEGER,
  calories INTEGER,
  best_season TEXT,       -- JSON 数组
  ingredients TEXT,       -- JSON 数组
  steps TEXT,             -- JSON 数组
  image TEXT,
  video TEXT,
  tips TEXT
);

CREATE TABLE diet_records (
  id TEXT PRIMARY KEY,
  date TEXT NOT NULL,
  recipe_id TEXT NOT NULL,
  meal_type TEXT,
  fullness TEXT,
  mood TEXT,
  FOREIGN KEY (recipe_id) REFERENCES recipes(id)
);

CREATE TABLE shopping_items (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT,
  checked INTEGER DEFAULT 0,
  source_recipe TEXT
);

CREATE TABLE user_preferences (
  key TEXT PRIMARY KEY,
  value TEXT
);
```

## 9. 代码规范

### 9.1 文件命名
- 组件文件：PascalCase（如 `RecipeDetail.tsx`）
- 工具文件：kebab-case（如 `use-local-storage.ts`）
- 类型文件：index.ts（统一导出）

### 9.2 导入顺序
1. React / 框架
2. 第三方库
3. 内部组件（`@/components`）
4. 工具函数（`@/lib`）
5. 类型（`@/types`）
6. 样式

### 9.3 样式规范
- 使用 Tailwind 工具类为主
- 复杂条件类名使用 `cn()` 工具函数
- 避免内联样式
- 动画过渡统一使用 `duration-300`
